# Rulantica Vildfål experience

Static GitHub Pages copy of the [published visitor account](https://my-rulantica-vildfal-experience.simong5.chatgpt.site/), with English, French, German, Spanish, Portuguese and Arabic pages. The anonymized transcription of the insurer letter is included.

## Publish

Create a public repository named `rulantica-vildfal-experience`, add the contents of this directory to its `main` branch, then select **Settings → Pages → Build and deployment → GitHub Actions**. The workflow publishes `site/` at `https://gsimon-ops.github.io/rulantica-vildfal-experience/`.

The canonical and alternate language links point to the original Sites publication so search engines can identify the primary version. The GitHub copy does not contain the source screenshot or personal details from it.
